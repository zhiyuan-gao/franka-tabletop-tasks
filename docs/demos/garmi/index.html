GARMI / MOBILE MANIPULATION

A learned grasp inside a CRAM household task

Navigate to the kitchen counter, pick up a bowl, and place it on the dining table. Reinforcement learning controls the mobile base and right arm during the grasp approach; CRAM handles navigation, transport and placement.

How the task runs

01 · CRAM

Reach the counter

Navigate to the left side of the counter and prepare the arm for policy control.

02 · RL

Approach together

The policy adjusts the base and seven right-arm joints using robot state and a grasp reference.

03 · FIXED CONTROLLER

Close and lift

Close the fingers, lift the bowl, and verify that the physical grasp remains stable.

04 · CRAM

Carry and place

Move to the dining table, release the bowl, verify support and stability, and retract the arm.

Inside the experiment

The policy was trained with Giskard expert demonstrations, corrective expert labels, and PPO, using 40 reference grasps and randomized initial states. This interactive demo uses the trained checkpoint 7500 and one fixed, validated left-counter setup with reference bowl-r020.

The workspace includes the Isaac Sim camera view, task progress, NeemHub, VS Code and JupyterLab. Each run saves its own video and task report. This recorded run passed the physical release, support and stability checks; the bowl's horizontal placement error was approximately 6.7 mm.
