GARMI demo

A clearer view of mobile grasping

The left-counter setups vary both the bowl position and the robot's initial positions. The camera views the bowl from the opposite side of the wrist. Every case uses the same trained checkpoint 7500 and reference bowl-r020. CRAM navigates to the specified handover position; RL then controls the mobile base and right arm. Closing and lifting use the fixed controller, followed by CRAM transport and placement. Case 05 is an explicitly marked follow-up to case 04 with the handover goal moved inward; the original rejected attempt is retained.

Recorded results: 4/5 complete tasks. These are demonstration cases, not a success-rate evaluation. Coordinates use the apartment map frame; playback follows simulation time, not wall-clock time. Run details and clip provenance.
