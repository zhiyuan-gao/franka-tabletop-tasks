# YCB asset provenance

The meshes in this directory are derived from the Yale-CMU-Berkeley (YCB)
Object and Model Set and are used under the dataset's CC BY 4.0 license.

- `011_banana.usd`: YCB `011_banana`.
- `017_orange.usd`: YCB `017_orange`, Google 16k scan. Used as the closest
  available YCB proxy for the mandarin in the two-fruit videos.
- `029_plate.usd`: YCB `029_plate`, Google 16k scan. Its material is overridden
  by the task scene to match the purple target and green distractor plates.

Official source page: https://ycb-benchmarks.s3.amazonaws.com/index.html

Downloaded archives:

- https://ycb-benchmarks.s3.amazonaws.com/data/google/017_orange_google_16k.tgz
- https://ycb-benchmarks.s3.amazonaws.com/data/google/029_plate_google_16k.tgz
